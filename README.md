# mern_template
# NOTE THIS PROJECT IS STILL A WORK IN PROGRESS
bare bones MERN template. Has everything needed to get started with nothing more

Setup:
- install node.js
- install MS Code
- setup a mongoDB database - there are many ways to do this. I set one up locally for simplicity
- copy over all the contents to a directory of your choice
- open MS Code and map it to the folder.
- CTL-J to open the CLI prompt
  - npm init -y
  - npm install express
  - npm install mongoose
  - npm install modemon
